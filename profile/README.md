# St CORTEX Lab

**Smart Cognitive Robot Dexterity Lab** · University of St Andrews

We research how robots can achieve human-like dexterity through perception, learning and cognition.

**Research leads:** [Prof Juan Ye](https://www.st-andrews.ac.uk/computer-science/people/jy31/) · [Dr Kasim Terzić](https://www.st-andrews.ac.uk/computer-science/people/kt54/) · [Dr Halid A. Kadi](https://www.st-andrews.ac.uk/computer-science/people/ah390/) (founder & lab manager)
